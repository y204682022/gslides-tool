gslides-tool

這是一個自己用的命令列小工具，透過 Google Slides API 和 Google Drive API，讀取和修改使用者自己的 Google 簡報：列出投影片內容、替換表格或文字框的文字、匯出 pptx／PDF 備份。

工具只在使用者自己的電腦上執行，不提供公開服務，也不收集任何人的資料。

gslides-tool is a personal command-line tool that uses the Google Slides API and Google Drive API to read and edit the user's own Google Slides presentations. It runs only on the user's own computer and is not offered as a public service.
