gslides-tool 隱私權政策

最後更新：2026-10-29

存取哪些 Google 資料

授權後，工具會用 Google Drive API 搜尋、複製、匯出使用者雲端硬碟裡的簡報檔，並用 Google Slides API 讀取和修改使用者指定的簡報內容。只有在使用者自己下指令時才會存取。

資料存放在哪裡

OAuth token 和改檔前自動匯出的備份檔，只存放在使用者自己的電腦上，不會上傳到其他伺服器。

分享與轉移

工具不會把任何 Google 使用者資料分享、出售或轉移給第三方，也不會用於廣告或用來訓練模型。

撤銷授權

隨時可以到 Google 帳戶的第三方存取權頁面 移除 gslides-tool 的存取權，再刪除電腦上的 token 檔即可。

Summary in English

gslides-tool accesses the user's Google Drive files and Google Slides presentations only when the user runs a command. OAuth tokens and backup exports are stored only on the user's own computer. No Google user data is shared, sold, transferred to third parties, used for advertising, or used to train models. Access can be revoked at any time at myaccount.google.com/permissions. gslides-tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
